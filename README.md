# BikEEE &#128690;

![Image](bikeee.png)

BikEEE is a new online marketplace specialized on pedelec classified ads in the Berlin region. This is the place where trusted private sellers and smart buyers meet for trading electric bikes.

# Getting Started

## Setup

In the project directory, run the following commands: 
```
$ npm install
$ npm start
```

## Using the app
&#10145;&#65039; Navigate to [http://localhost:3000](http://localhost:3000/) to view it in your browser

&#10145;&#65039;  Upload ```CSV``` file as instructed

&#10145;&#65039;  The result will be displayed in the app
